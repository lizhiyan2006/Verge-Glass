# Verge-Glass
基于Clash Verge Rev 2.5.8 的第三方美化版本，拥有背景透明；更换背景图和 文字、图标、卡片玻璃独立控制透明度的各种自定义美化功能；

我的两台电脑都是win10 22h2，实测可用，win11支持情况不清楚；

自动更新已关闭（否则会被上游版本覆盖），内核可以在「设置 → 内核」里更新；

非官方构建，与上游项目无关；代码基于 GPL-3.0 的 Clash Verge Rev 源码；本项目为vibecode项目，deepseek协助开发；

由于时间原因 目前上传的文件有点杂，包含了前期基于原版软件注入插件的内容，不过由于效果不佳我放弃了这个想法，转向用原版文件重写了一个改版clash，也就是这个项目目前的效果
有时间的话我会整理的，各位见谅
