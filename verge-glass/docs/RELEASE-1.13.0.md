# Verge Glass · 1.13.0（Windows x64）

Clash Verge Rev **2.5.9** 的第三方改版：把「窗口透明度」和「内容透明度」彻底拆开——
窗口自带 alpha 通道，页面留空的地方**就是桌面**；文字、图标、卡片玻璃各自独立控制。
glass 主题编译进二进制，不需要插件、脚本或调试端口，桌面快捷方式直接启动也是这个效果。

> 非官方构建，与上游项目无关。代码基于 GPL-3.0 的 Clash Verge Rev 源码。

---

## 这一版改了什么

### 1. 修「关掉窗口再打开就冒出一圈外框」

窗口客户区只有 1991×1326，而窗口矩形是 2015×1338 —— 四周那圈 **12px 非客户区**是 Windows
给顶层窗口保留的隐形缩放边框。托盘隐藏 → 再显示时它会被窗口类画刷涂出来，就是你看到的框；
调整窗口大小之所以能修好，是因为重建区域把它又挡回去了。

- 现在用 `DWMNCRP_DISABLED` 让 DWM **完全不渲染非客户区**，白框从源头消失；
- 区域从「客户区 +1px」改成**精确等于客户区**，右/下边那条 1px 白线一并没了；
- 守护线程监视 `IsWindowVisible`，一旦从隐藏变可见就跑一次完整修复阶梯（120/400/900ms），
  即使区域真的丢了也会在 1.5 秒内自愈。

### 2. 「背景模糊」删除，只留「图片模糊」

`backdrop-filter` 只能模糊**页面内部**的图层，真透明窗口后面是桌面，CSS 永远模糊不到它。
所以那个滑杆在「全透明」背景下必然没反应——留着只会让人以为坏了。这一版把它的
功能、位置、「实验性」标签和说明整行移除，只保留真正有效的「图片模糊」。
面板玻璃的模糊沿用上次保存的值，观感不变。

### 3. 卡片瘦身后的最终形态

```
外观    基调 · 不透明度
背景    背景（全透明 / 桌面壁纸 / 自选图片）· 背景可见度 · 图片模糊 · 背景遮罩
内容    内容不透明度
```

### 4. 单文件直装包 + 第三方标识

- 一个 exe 装完，简体中文安装界面，glass 图标（16→256px 七档）已内嵌；
- 版本信息里写明第三方改版：`CompanyName: Verge Glass 第三方改版（非官方）`、
  `LegalCopyright: GPL-3.0 · 第三方改版（非官方）…`；
- 主题卡片副标题显示 `Verge Glass 第三方改版（非官方） · 构建 2026-10-29 03:01`。

## 安装

双击 `VergeGlass-Setup.exe` 即可，默认装到 `C:\Program Files\Clash Verge`（需要管理员）。
静默安装：

```powershell
.\VergeGlass-Setup.exe /S
```

`productName` / 安装目录 / 卸载项 / `identifier` 与原版一致，所以是**覆盖升级**，不会装出第二份；
原有配置、订阅、规则、内核都在。卸载走「应用和功能」里的 Clash Verge。

## 你可能想先知道的

- **只支持 Windows**（依赖 WebView2 + DWM 透明合成），已在 Windows 10 22H2 19045 / WebView2 156 实测；
- **应用自更新已关闭**（否则会被上游版本覆盖），内核（mihomo）照常在「设置 → 内核」里更新；
- **没有系统阴影**，也没有 Windows 11 的贴边分屏布局提示；
- **模糊不了桌面**：CSS 的能力边界，想要「真·亚克力」得上 DWM 合成层，本项目没走那条路；
- 窗口圆角、窗口按钮、悬停提示（最小化 / 最大化 / 关闭）都是自绘的，配色跟随深浅色。

## 已知问题

- 175% / 混合 DPI 多显示器下，窗口跨屏移动偶发 1px 边缘差异（重建区域后自愈）；
- 极个别显卡驱动上 `backdrop-filter` 与 DWM 透明合成叠加会出现一帧花屏，切一次窗口即恢复。
